# 📊 Business Sales Performance Analytics

## Internship Project

This project was completed as **Task 1** during my **Future Interns Data Analysis Internship**. The objective was to analyze business sales data, identify key performance indicators (KPIs), and create an interactive dashboard with actionable business insights.

---

## Project Objective

The objective of this project is to analyze Superstore sales data to identify:
- Revenue trends
- Top-selling products
- High-value categories
- Regional performance
- Business insights and recommendations

---

## Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook (VS Code)
- Power BI Desktop

---

## Dataset

- Superstore Sales Dataset
- Rows: 9,994
- Columns: 21

---

## Dashboard Features

- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Average Sales KPI
- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Profit by Category
- Top 10 Products
- Top 10 Customers
